      Moteur arrière : stator, onduleur, dissipateur
      
        
      Sur une Model 3 LFP, la batterie est surtout chauffée par le moteur arrière. Pour recevoir ces températures, active le Profiler dans Tessie (web) : elles arrivent alors par le flux en direct et s'affichent dans le graphique « Moteur arrière » et la pastille « Moteur arr. ». Le bouton « Activer ces 3 champs » (modification de la configuration de télémétrie) n'est utile que sans le Profiler.
